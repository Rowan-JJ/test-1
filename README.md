# 亚马逊 Listing 标题与五点助手

一个纯前端的工具，用于管理关键词、为不同 SKU 组合标题，并调用 DeepSeek API 生成符合亚马逊规范的五点描述。

## 功能概览

- 关键词录入：输入关键词、热度变化、搜索排名并指定类型及颜色，所有关键词会进入关键词库。
- 类型管理：为核心词（默认红）、特征词（默认蓝）、场景词（默认绿）、小语种词（默认紫）设置默认颜色，新建关键词自动继承，可随时调整并同步刷新已使用的词。
- 批量分类：在关键词管理面板中粘贴多行关键词信息，系统会先放入“预备关键词”面板并调用 DeepSeek 自动识别类型后再加入词库，失败项可重新识别或移除。
- 拖拽操作：将关键词滑块拖入任意标题框，支持排序、跨 SKU 调整及移除。
- 标题限制：左侧可自定义 SKU 与副标题字符上限，标题区实时显示字符计数并在超限时高亮提示，拖拽也会自动阻止超限或重复词。
- 标题导出：单独复制某个标题或副标题，并支持按空行拼接整个 SPU 下所有 SKU 标题。
- SPU/SKU 管理：为每个 SPU 输入产品信息（标题区仅显示简要摘要），灵活新增或删除 SKU，并支持批量粘贴多行名称一次创建。
- 自动生成：按照“核心词1 + 特征词 + 核心词2 + 特征词 + 场景词 + 小语种词”公式为 SPU 副标题及全部 SKU 自动分配关键词，确保字符数符合限制，可再拖拽微调。
- 五点生成：输入 DeepSeek API Key 后，可基于产品信息生成英文五点描述，并支持自定义提示词。

## 使用方法

1. 打开 `index.html` 即可在浏览器内使用。
2. 在左侧添加关键词并设定类型，或通过「批量上传关键词」粘贴多行信息，等待预备区分类完成后自动进入词库。
3. 在右侧创建 SPU 并填写产品信息，可单个新增 SKU，或通过「批量添加 SKU」粘贴多行一次创建；同一面板可设置标题长度上限。
4. 需要快速排布时，点击「自动生成标题」会在字符限制内按照公式为副标题与各个 SKU 自动分配词语。
5. 点击标题区域内的「导出标题」、「批量导出 SKU 标题」或「导出副标题」即可复制组合后的文本。
6. 输入 DeepSeek API Key 并设置提示词后，展开「五点生成」即可调用 API 返回英文五点描述并展示在页面中。

> **安全提示**：为了避免泄露密钥，推荐在使用时手动输入 API Key，代码不会保存或上传该密钥。

## 自定义与扩展

- 所有数据存储在浏览器内存中，如需持久化可将 `state` 对象持久化到本地存储或后端接口。
- 可根据实际需求扩展关键词属性、SKU 信息以及导出逻辑。

## 本地开发

本项目为静态站点，无需构建步骤。可以使用任意静态文件服务器（如 `npx serve`）进行本地预览，也可以直接通过浏览器打开 `index.html`。
