# 亚马逊 Listing 标题与五点助手

一个纯前端的工具，用于管理关键词、为不同 SKU 组合标题，并调用 DeepSeek API 生成符合亚马逊规范的五点描述。

## 功能概览

- 顶部导航：新增常驻导航栏，可一键跳转到商品结构、关键词、关键词库、标题编辑与预览等主要板块。
- 关键词录入：输入关键词、热度变化、搜索排名并指定类型及颜色，所有关键词会进入关键词库，库内自动按热度排序。
- 类型管理：为核心词（默认红）、特征词（默认蓝）、场景词（默认绿）、小语种词（默认紫）设置默认颜色，新建关键词自动继承，可随时调整并同步刷新已使用的词，并在关键词库顶部查看颜色提示；核心词需满足搜索排名为 A，若排名不是 A（包括缺失）将自动归类为特征词。
- 关键词库：全宽吸顶展示并按四个类型分栏，新增收起/展开按钮，方便在编辑标题时暂时隐藏；卡片右上角可删除单个词，或点击编辑图标修改词类型、热度、排名信息，变更后会自动更新颜色及在各处的显示，并支持一键“导出关键词”复制所有词库数据。
- 批量分类：在关键词管理面板中粘贴多行关键词信息，系统会先放入同面板内的“预备关键词”区并调用 DeepSeek 自动识别类型后再加入词库，失败项可重新识别或移除，并在检测到失败时显示“重新识别全部失败词”按钮一键重试。
- 拖拽操作：将关键词滑块拖入任意标题框，支持排序、跨 SKU 调整及移除。
- 标题限制：左侧可自定义 SKU、父标题与 Search Term 字符上限，标题/Search Term 区域实时显示字符计数并在超限时高亮提示。
- 文案导出：单独复制某个标题或父标题，并支持按空行拼接整个 SPU 下所有 SKU 标题；预览区提供“文案导出”“复制标题”“复制 Search Term”按钮，可随时汇总最新文案并复制。
- 逐词细分：父标题、SKU 标题与 Search Term 区域均提供「逐词细分」按钮，可将彩色关键词块拆分成白色单词块继续拖放；拆分后可使用「删除多余重复词」按钮一键从末尾开始清理超过两次的重复细分词；标题下方的标注区会以淡红色高光叠加显示命中的关键词，鼠标悬停即可查看热度与排名气泡提示。
- Search Term 生成：每个 SKU 拥有色块拖拽式的 Search Term 面板，按照“20% 核心词 + 20% 特征词 + 40% 场景词 + 20% 小语种词”分配未用关键词，优先使用热度更高的词，并自动避免颜色冲突、边界重复与单词超出两次的情况。系统会实时排除已经在对应标题中出现过的关键词，若当前 SKU 尚未生成标题则会提示先完成标题生成再创建 Search Term。生成后仍可手动调整顺序，字符上限由商品结构面板统一控制，支持单个或批量生成并导出。
- 标题预览：预览区按 SPU 聚合展示父标题、各 SKU 标题与 Search Term，依次排布在淡绿色背景框内，配合逐词高光、词频统计与文案导出，支持就地“编辑”修改文案并实时同步统计。
- AI 审查：顶部“AI 审查”按钮会调用 DeepSeek 校验全部标题与 Search Term，检查字符上限、品牌词与违禁词、单词重复次数等合规项；通过项在框体右侧显示对勾，存在问题的条目会标记淡红背景并在悬浮提示中说明原因；若检测到恰好重复两次或疑似违禁词，则显示黄色问号提示进一步核对。
- 导出格式：复制按钮默认输出纯文本换行格式，便于直接粘贴到 Excel；预览卡片本身保留完整的 SPU/SKU 标识信息，可随时核对来源。
- SPU/SKU 管理：为每个 SPU 输入产品信息，标题区聚焦展示 SPU 名称，商品结构面板内新增 SPU 列表显示前 100 字详情并可展开阅读全文，灵活新增或删除 SKU，并支持批量粘贴多行名称一次创建。
- 自动生成：按照“品牌词（Popilush） + 核心词1 + 特征词1 + 核心词2 + 特征词2 + 特征词3 + 场景词1 + 场景词2 + 颜色词（Color + 色彩） + 尺码词（Size + 尺码）”公式为 SPU 父标题及全部 SKU 自动分配关键词，其中父标题不附加颜色/尺码；SKU 标题会根据 SKU 编码自动识别颜色（RD=Red、BK=Black、YH=Leopard Print、GR=Green、PK=Pink、BN=Brown、WH=White、SK=Skin 等）与尺码（XS、S、M、L、XL、XXL、3XL），无法解析时先询问是否调用 AI 辅助识别，再退回到人工输入。算法会优先覆盖使用次数少的高热度词汇，避免不同 SKU 生成完全相同的组合，同时保证相邻词不会首尾重复、核心词根尽量不重复，并自动过滤与 SKU 颜色冲突的关键词、控制单词在同一标题内最多出现两次，仍可拖拽微调；当某一类型的候选词暂时不足时，会在不突破单词重复限制的前提下重复利用高热度词汇并提示需要补充，以尽量完成公式要求。
- 导出格式：标题复制时会自动转换为首字母大写（常见介词除外），Search Term 复制则统一为小写文本，便于直接粘贴到 Excel。
- 词频分析：标题与 Search Term 预览均可生成词频统计，并显示“出现次数 + 占比（词频数 /（SKU 数 + 1））”，支持清空结果重新统计。
- 五点生成：默认预填官方 DeepSeek API Key，可直接使用或点击“修改秘钥”替换，在预览区底部为每个 SPU 设置提示词并生成英文五点描述。

## 使用方法

1. 打开 `index.html` 后根据提示输入访问码 `zjj123456`，解锁全部功能。
2. 在右上角的关键词面板添加关键词并设定类型，或通过「批量上传关键词」粘贴多行信息，等待预备区分类完成后自动进入词库；若有词分类失败，可直接点击出现的“重新识别全部失败词”批量重试。
3. 在左上角的商品结构面板创建 SPU 并填写产品信息，可单个新增 SKU，或通过「批量添加 SKU」粘贴多行一次创建；同一面板可设置标题、父标题与 Search Term 的字符上限。
4. 需要快速排布时，点击「自动生成标题」会在字符限制内按照默认公式为父标题与各个 SKU 自动分配词语。
5. 在每个 SKU 的 Search Term 面板中，可点击「生成 Search Term」按比例填充未使用的关键词，字符上限由商品结构面板统一控制；也可使用“批量生成 Search Term”一次性处理全部 SKU。
6. 点击标题或 Search Term 区域的导出按钮，或在预览区使用“文案导出”“复制标题”“复制 Search Term”等操作，即可复制当前或全部 SPU 的标题与 Search Term，并可在预览区执行词频统计或 AI 审查。
7. 默认已填入测试用 DeepSeek API Key，点击「修改秘钥」可替换为自己的密钥，设置提示词后展开「五点生成」即可调用 API 返回英文五点描述并展示在页面中。

> **安全提示**：界面默认填入测试用 API Key，仅保存在浏览器内存中，正式使用时建议通过「修改秘钥」替换为自己的密钥并妥善保管。

## 自定义与扩展

- 所有数据存储在浏览器内存中，如需持久化可将 `state` 对象持久化到本地存储或后端接口。
- 可根据实际需求扩展关键词属性、SKU 信息以及导出逻辑。

## 本地开发

本项目为静态站点，无需构建步骤。可以使用任意静态文件服务器（如 `npx serve`）进行本地预览，也可以直接通过浏览器打开 `index.html`。
