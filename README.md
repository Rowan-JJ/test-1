# 亚马逊 Listing 标题与五点助手

一个纯前端的工具，用于管理关键词、为不同 SKU 组合标题，并调用 DeepSeek API 生成符合亚马逊规范的五点描述。

## 功能概览

- 顶部导航：新增常驻导航栏，可一键跳转到商品结构、关键词、关键词库、标题编辑与预览等主要板块。
- 关键词录入：输入关键词、热度变化、搜索排名并指定类型及颜色，所有关键词会进入关键词库，库内自动按热度排序。
- 类型管理：为核心词（默认红）、特征词（默认蓝）、场景词（默认绿）、小语种词（默认紫）设置默认颜色，新建关键词自动继承，可随时调整并同步刷新已使用的词，并在关键词库顶部查看颜色提示；核心词需满足搜索排名为 A，若排名不是 A（包括缺失）将自动归类为特征词。
- 关键词库：全宽吸顶展示并按四个类型分栏，可在卡片右上角删除单个词，或点击编辑图标修改词类型、热度、排名信息，变更后会自动更新颜色及在各处的显示。
- 批量分类：在关键词管理面板中粘贴多行关键词信息，系统会先放入同面板内的“预备关键词”区并调用 DeepSeek 自动识别类型后再加入词库，失败项可重新识别或移除，并在检测到失败时显示“重新识别全部失败词”按钮一键重试。
- 拖拽操作：将关键词滑块拖入任意标题框，支持排序、跨 SKU 调整及移除。
- 标题限制：左侧可自定义 SKU、父标题与搜索词字符上限，标题/搜索词区域实时显示字符计数并在超限时高亮提示。
- 标题导出：单独复制某个标题或父标题，并支持按空行拼接整个 SPU 下所有 SKU 标题，或在预览区通过“批量导出标题/搜索词”“导出结果”快速汇总并复制。
- 搜索词生成：每个 SKU 拥有色块拖拽式的搜索词面板，按照“20% 核心词 + 20% 特征词 + 40% 场景词 + 20% 小语种词”分配未用关键词，可手动调整顺序，字符上限由商品结构面板统一控制，支持单个或批量生成并导出。
- 标题预览：预览区按标题与搜索词分栏显示全部 SPU 的内容，可分别复制、统计词频、调用 AI 去除重复词汇，并在 AI 调整结果旁显示字符数。
- 导出模式：标题与搜索词的批量导出支持“简化（纯文本换行）”与“完整（含编号与标识）”两种模式，默认使用简化模式便于粘贴到表格，可随时切换并应用到复制/导出操作。
- SPU/SKU 管理：为每个 SPU 输入产品信息，标题区聚焦展示 SPU 名称，商品结构面板内新增 SPU 列表完整展示产品详情，灵活新增或删除 SKU，并支持批量粘贴多行名称一次创建。
- 自动生成：按照“品牌词（Popilush） + 核心词1 + 特征词1 + 核心词2 + 特征词2（可含多词） + 场景词（可含多词） + 尺码信息（Color Size）”公式为 SPU 父标题及全部 SKU 自动分配关键词，其中父标题不附加尺码信息，SKU 标题会根据 SKU 编码自动识别颜色（RD=Red、BK=Black、YH=Leopard Print、GR=Green、PK=Pink、BN=Brown、WH=White，识别失败会提示输入）与尺码（XS、S、M、L、XL、XXL、3XL）填充至“Color/Size”片段，算法优先选择热度高、整体使用次数少且核心词根不重复的组合，并尽量填满字符上限，仍可拖拽微调。
- 五点生成：默认预填官方 DeepSeek API Key，可直接使用或点击“修改秘钥”替换，在预览区底部为每个 SPU 设置提示词并生成英文五点描述。

## 使用方法

1. 打开 `index.html` 后根据提示输入访问码 `zjj123456`，解锁全部功能。
2. 在右上角的关键词面板添加关键词并设定类型，或通过「批量上传关键词」粘贴多行信息，等待预备区分类完成后自动进入词库；若有词分类失败，可直接点击出现的“重新识别全部失败词”批量重试。
3. 在左上角的商品结构面板创建 SPU 并填写产品信息，可单个新增 SKU，或通过「批量添加 SKU」粘贴多行一次创建；同一面板可设置标题、父标题与搜索词的字符上限。
4. 需要快速排布时，点击「自动生成标题」会在字符限制内按照默认公式为父标题与各个 SKU 自动分配词语。
5. 在每个 SKU 的搜索词面板中，可点击「生成搜索词」按比例填充未使用的关键词，字符上限由商品结构面板统一控制；也可使用“批量生成搜索词”一次性处理全部 SKU。
6. 点击标题或搜索词区域的导出按钮，或在预览区使用“批量导出标题/搜索词”“复制”“导出结果”等操作，即可复制当前或全部 SPU 的标题与搜索词，并可在预览区执行词频统计或 AI 调整。
7. 默认已填入测试用 DeepSeek API Key，点击「修改秘钥」可替换为自己的密钥，设置提示词后展开「五点生成」即可调用 API 返回英文五点描述并展示在页面中。

> **安全提示**：界面默认填入测试用 API Key，仅保存在浏览器内存中，正式使用时建议通过「修改秘钥」替换为自己的密钥并妥善保管。

## 自定义与扩展

- 所有数据存储在浏览器内存中，如需持久化可将 `state` 对象持久化到本地存储或后端接口。
- 可根据实际需求扩展关键词属性、SKU 信息以及导出逻辑。

## 本地开发

本项目为静态站点，无需构建步骤。可以使用任意静态文件服务器（如 `npx serve`）进行本地预览，也可以直接通过浏览器打开 `index.html`。
