# 亚马逊 Listing 标题与五点助手

一个纯前端的工具，用于管理关键词、为不同 SKU 组合标题，并调用 DeepSeek API 生成符合亚马逊规范的五点描述。

## 功能概览

- 关键词录入：输入关键词、热度变化、搜索排名并指定类型及颜色，所有关键词会进入关键词库。
- 类型管理：为核心词、特征词、场景词、小语种词设置默认颜色，新建关键词自动继承，可随时调整并同步刷新已使用的词。
- 拖拽操作：将关键词滑块拖入任意标题框，支持排序、跨 SKU 调整及移除。
- 标题导出：一键复制标题框或副标题框内关键词组合后的文本。
- SPU/SKU 管理：为每个 SPU 输入产品信息，灵活新增或删除 SKU，并支持批量粘贴多行名称一次创建。
- 自动生成：按照“核心词1 + 特征词 + 核心词2 + 特征词 + 场景词 + 小语种词”公式为 SPU 副标题及全部 SKU 自动分配关键词，可再拖拽微调。
- 五点生成：输入 DeepSeek API Key 后，可基于产品信息生成英文五点描述，并支持自定义提示词。

## 使用方法

1. 打开 `index.html` 即可在浏览器内使用。
2. 在左侧添加关键词并设定类型，关键词会显示在词库中，可以拖拽至任意标题框。
3. 在右侧创建 SPU 并填写产品信息，可单个新增 SKU，或通过「批量添加 SKU」粘贴多行一次创建。
4. 需要快速排布时，点击「自动生成标题」会按照公式为副标题与各个 SKU 自动分配词语。
5. 点击标题区域内的「导出标题」或「导出副标题」即可复制组合后的文本。
6. 输入 DeepSeek API Key 并设置提示词后，展开「五点生成」即可调用 API 返回英文五点描述并展示在页面中。

> **安全提示**：为了避免泄露密钥，推荐在使用时手动输入 API Key，代码不会保存或上传该密钥。

## 自定义与扩展

- 所有数据存储在浏览器内存中，如需持久化可将 `state` 对象持久化到本地存储或后端接口。
- 可根据实际需求扩展关键词属性、SKU 信息以及导出逻辑。

## 本地开发

本项目为静态站点，无需构建步骤。可以使用任意静态文件服务器（如 `npx serve`）进行本地预览，也可以直接通过浏览器打开 `index.html`。
